Movie Webpage

Context

For this project, we were asked by the teacher to create a webpage for a fictional movie so we could practice our HTML and CSS skills. With my partner, we created a webpage for the fictonal movie "What Remains Unseen." This movie is kind of like Harry Potter, but more sinister.

Content

In this project, we created a webpage for a fictional movie we created, "What Remains Unseen." My partner and I split up the work so we could get an opportunity to learn both in CSS and HTML. This included creating divs, classes, headings, adding images, and making the webpage look less bland.

Takeaways

There were a lot of things I learned while making this project such as time management and communication. We were given a week to complete this, and while this was a good amount of time, my schedule was often packed with other classwork. I had to sort those out before working on the project. Communication was also key, otherwise aspects of the project might conflict. We discussed the heading sizes, what color we wanted certain elements to be, who would do what, and generally how we wanted the page to look like.
